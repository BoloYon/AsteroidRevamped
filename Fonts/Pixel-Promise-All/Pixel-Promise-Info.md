# Pixel Promise
Pixel Promise is a 24pt pixel art font designed with rounded edges and some curvy flair.

## Author
[VEXED](https://v3x3d.itch.io/)

## Basic Info
- Base Glyph Height: 24px
- Scales: 24, 48, 72, 96, etc
- Ascender Max: 12px
- Descender Max: 9px
